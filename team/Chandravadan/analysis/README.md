# Event Correlation and Log Analysis

This module analyzes authentication and SDN controller logs generated by the project.

## Files
- `analyze_logs.py` — reads and summarizes authentication and controller events.
- `data/auth_log.json` — authentication event log.
- `data/controller_log.json` — SDN controller event log.
- `data/analysis_report.json` — generated analysis output.

## Run
From the repository root:

```bash
python3 team/Chandravadan/analysis/analyze_logs.py

```
